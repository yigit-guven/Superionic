- Added a master SuperionicConfig.enabled flag (with load/save support) and a ModMenu entry to toggle it. Added early-return guards in multiple mixins (Allocation, BatchRendering, ChestRenderer, ChunkLoading, EntityBatching, LeavesBlock, MobAi, Network, ParticleBatching) so all optimizations can be globally disabled at runtime; also include a small null-check and adjust compression threshold check to honor the new flag.
- Added a SuperionicConfig.getEnabledFeatureCount() method to count the number of enabled features, which is used in the Performance Toast to display the number of enabled features.
- Added a SuperionicConfig.getTotalSessionSavings() method to count the total savings of all enabled features, which is used in the Performance Toast to display the total savings.
